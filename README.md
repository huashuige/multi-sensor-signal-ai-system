# 项目简介

基于 Django 的 Web 系统整合了数据采集、信号处理和深度学习训练功能，支持实时多通道传感器数据采集、信号分析与深度学习在线训练，满足复杂工业监测和智能分析需求。
(相关文件结构作用与前端展示，可见技术说明文档)

---

## 核心功能

### 数据采集模块
- 通过 USB5121 数据采集卡实现多通道传感器数据采集，最多支持 16 个模拟输入通道
- 基于 WebSocket 技术，实现数据的实时展示与采集控制，可达到无延迟操作。
- 支持单次采集模式（固定采样点数）和连续采集模式（示波器模式）
- 可独立配置各传感器通道启用/禁用、量程设置、量纲转换（例：电压到某物理量）及采样率调整
- 自动将采集的传感器数据、采集配置参数及元数据存储至 MySQL 数据库
- 基于摄像头的仪表表盘读数功能，采用 OpenCV 模板匹配技术识别指针位置和数值

### 信号处理模块
- 支持时域和频域分析，包含 FFT 变换，并计算基本时域特征与频域特征量
- 实现高级信号处理算法，如局部倒谱编辑(与CPW、CEP和LCEP)和希尔伯特变换等等
- 实现时域平均算法，用于信号去噪和特征提取，支持各文件待处理信号与鉴相信号上传，采样率匹配，平均次数与窗口设置、信号对比效果提升等等

### 深度学习训练模块（基于 PyTorch）
- 利用采集的多通道传感器数据构建训练数据集，提供用户模式和专家模式两种训练配置，
- 支持多种深度学习模型训练，如 LSTM，CNN等，训练参数可自定义(训练集测试集合验证集合比例划分、训练轮次、学习率、batch、优化器、窗口等等参数，专家模式会更多例如隐藏单元、Dropout、学习率调度器等）
- 包含训练数据集管理（训练集合列表形式：标注模式、创建时间、通道等）、模型管理（支持编辑、查看、删除等等操作）及状态展示功能（训练中，未训练，已完成，暂停训练）
- 在线训练界面实时显示训练损失曲线（训练损失验证损失曲线）、学习率变化及训练日志（时间，轮数，损失率等），支持暂停等操作
- 预测界面自动识别输入通道数，展示每个通道的真实值与预测值对比曲线及性能指标（MAE、R² 等），可选择数据源与文件，可导出结果曲线，各通道评估指标

## 技术栈

- **后端**：Django 框架 + MySQL 数据库+WebSocket 实时通信
- **前端**：HTML5、JavaScript、CSS3（相关文件已在本地下载，无需联网）
- **硬件设备**：USB5121 多通道数据采集卡（通过 DLL 驱动控制，文件驱动在lib文件夹下）、工业相机
- **数据存储**：传感器原始数据、采集配置、训练数据集及模型均存储于 MySQL

---

## 项目亮点

- 完整覆盖传感器数据的采集、存储、处理和智能分析全流程
- 实时性能强，基于 WebSocket 技术实现高效数据传输与显示
- 信号处理与深度学习训练模块紧密结合，支持在线训练和预测，便于工业智能监测
- 多通道管理和参数灵活配置，适应复杂多样的工业现场需求
